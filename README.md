# Ja'fari Prayer Times — Wear OS Tile

Standalone Wear OS Tile for Samsung Galaxy Watch 5 Pro (and other Wear OS 3+ watches).

## Features
- **100% Offline Astronomical Calculation** (no internet required once GPS is acquired)
- **Calculation Methods:** Leva Research Institute (Qom) [Default] & University of Tehran
- **Display Modes:** 5 rows (Fajr, Sunrise, Dhuhr, Sunset, Maghrib) [Default] or 7 rows (+ Isha & Shari'i Midnight)
- **Clock Format:** 12-hour [Default] or 24-hour
- **Live Countdown** to the next prayer with highlighted active row
- **On-Watch Settings & GPS Refresh** right from the Tile

## Cloud Build (GitHub Actions)
Push this project to any GitHub repository. The included `.github/workflows/build-apk.yml` automatically compiles `app-debug.apk` under the **Actions** tab.
